## 1.0.0

- First release. / Erste Fassung.
- Page in Hostwerk's design: page head with title, text and actions, the usual side margins, filled key figures (they were empty), welcome with pictures while there is no own VM yet, card heads with icons and actions on the right, full-width cards, wide dialogs and colour tiles for the sources and app templates. / Seite im Hostwerk-Design: Kopfzeile, gewohnte Abstände, Kennzahlen gefüllt, Begrüßung mit Bildern, Kartenköpfe mit Icons, breite Dialoge und Farbkacheln für Quellen und Anwendungen.
- 3D graphics verified (virgl on the host's graphics card, about 65–95 fps in glmark2): the own QEMU window now really opens (Hostwerk had hidden it for every "Own window" VM – needs the new hide option of Hostwerk's process start), the health check names 3D VMs whose cloud kernel has no 3D driver, and the PNG screen of such a VM explains where the picture is. / 3D-Grafik geprüft (virgl auf der Grafikkarte, ca. 65–95 fps): das eigene QEMU-Fenster geht jetzt wirklich auf (war bei jeder VM mit „Eigenes Fenster“ versteckt), der Gesundheits-Check nennt 3D-VMs mit Cloud-Kernel ohne 3D-Treiber, der Bildschirm erklärt, wo das Bild ist.
- Clipboard with Windows verified both ways (incl. ä ö ü ß €) through QEMU's vdagent and the SPICE agent of the virtio-win guest tools; guest commands in Windows now answer in UTF-8 (umlauts were garbled). / Zwischenablage mit Windows in beide Richtungen geprüft (inkl. Umlauten, ß, €); Befehle im Windows-Gast antworten jetzt in UTF-8.
- Windows 11 installs without clicking under WHPX (verified, 11 min): Windows VMs get a named CPU model of the host vendor (with "max" Windows crashes with 0x50), restart through a new QEMU process (a reset pauses WHPX VMs), and the password-holding copies of the answer file are deleted first at logon and again by Hostwerk. / Windows 11 installiert sich unter WHPX ohne Klicks (geprüft, 11 Min.): eigenes CPU-Modell je Hersteller, Neustart über einen neuen QEMU-Prozess, Kopien der Antwortdatei mit Passwort werden doppelt gelöscht.
- QEMU engine with hardware acceleration (WHPX, KVM, HVF; TCG fallback). / QEMU-Engine mit Hardware-Beschleunigung (WHPX, KVM, HVF; TCG als Rückfall).
- Ready-made Linux VMs from official cloud images (Debian 12/13, Ubuntu 22.04/24.04, AlmaLinux 9, Fedora) with cloud-init: user, password/SSH key, host name, time zone, guest agent; every download checked against the published checksum. / Fertige Linux-VMs aus offiziellen Cloud-Images mit cloud-init; jeder Download gegen die veröffentlichte Prüfsumme geprüft.
- Installer ISOs (Alpine, Debian, Ubuntu from the catalogue or any own ISO; Windows with UEFI/SATA/e1000e). / Installer-ISOs (Katalog oder eigene ISO; Windows mit UEFI/SATA/e1000e).
- Screen inside Hostwerk (frames only when changed, mouse, keyboard by physical key, typing text, Ctrl+Alt+Del …) or an own window; serial console. / Bildschirm in Hostwerk oder eigenes Fenster; serielle Konsole.
- Snapshots while running (disk snapshots with file-system freeze through the guest agent; with memory on KVM/HVF/TCG), restore, tree. / Snapshots im Betrieb, Zurückspielen, Baum.
- Templates with linked clones, full copies, port forwarding changed live, ISO change while running, disks add/grow/remove. / Vorlagen mit verknüpften Klonen, Portweiterleitung live, ISO-Wechsel im Betrieb.
- Backups while running (QEMU block backup, compressed) in Hostwerk's backup centre; restore. / Sicherungen im Betrieb in der Sicherungs-Zentrale.
- Import: VirtualBox VMs, OVA/OVF, VDI/VMDK/VHD(X)/qcow2/raw; export as VDI/VMDK/VHDX/VHD/qcow2. / Import und Export.
- VirtualBox VMs next to QEMU VMs: start, shut down, pause, save state, snapshots, screenshot, typing; only VMs Hostwerk created can be deleted. / VirtualBox-VMs in derselben Liste.
- Service kind "vm": overview, search, scheduled tasks, autostart, crash restart, clean shutdown when Hostwerk quits, audit log, health hints, dashboard tile. / Dienst-Art „vm“ in ganz Hostwerk.
- Internal networks between VMs (switch inside Hostwerk on 127.0.0.1, static addresses through cloud-init or the guest agent). / Interne Netze zwischen VMs.
- Shared folders PC → VM over a local WebDAV server (Linux mounts them by itself, Windows as a network drive). / Freigegebene Ordner vom PC in die VM.
- Network bridge through an existing TAP adapter (detection only, nothing installed). / Netzwerkbrücke über einen vorhandenen TAP-Adapter.
- Encrypted disks (qcow2 LUKS, key sealed in Hostwerk's secret store). / Verschlüsselte Platten.
- Moving, mirroring, keeping and cloning VMs through Hostwerk's "move to another computer". / VMs auf einen anderen Rechner umziehen.
- App templates for ready-made Linux (Nginx, Docker host, WordPress with MariaDB, Nextcloud, Gitea, Uptime Kuma): packages, setup at the first start, port forwards and an "Open …" button on the VM page; own commands and a bash script at the first start (safely quoted, run once). WordPress, Nextcloud, Gitea and Uptime Kuma verified live: installed, used and back with their data after a VM restart. / Anwendungs-Vorlagen für fertiges Linux mit Portweiterleitung und „… öffnen“-Knopf; eigene Befehle und Bash-Skript beim ersten Start. WordPress, Nextcloud, Gitea und Uptime Kuma live geprüft (eingerichtet, benutzt, nach Neustart mit Daten wieder da).
- Ask AI about the screen: sends the VM's state, guest agent facts and the last serial console lines as text (the picture stays on the PC – the SDK carries text only); clear refusal while the AI is off. AI tools for the chat: list, screen as text, start, shut down, create from an app template or a VM template – changing ones ask first in plain words. / KI zum Bildschirm fragen (nur Text) und KI-Werkzeuge mit Freigabe in Klartext.
- Hyper-V VMs in the list (read-only through PowerShell, start/shut down/turn off/checkpoint with administrator rights); quietly "not available" on Windows Home. / Hyper-V-VMs in der Liste; auf Windows Home still „nicht verfügbar“.
- ARM64 VMs through qemu-system-aarch64 (machine "virt", UEFI, virtio, emulated – slow) and ARM64 cloud images of Debian 12/13 and Ubuntu 24.04. / ARM64-VMs (emuliert, langsam) und ARM64-Cloud-Images.
